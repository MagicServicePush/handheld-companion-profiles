## About

Handheld Companion Profiles Manager helps handheld PC gamers organize their per-game controller and TDP configurations. Save power profiles, document button mapping layouts and track performance settings per game.

---

## Features

| Feature | Description |
|---------|-------------|
| **Power Profiles** | Save TDP and fan curve configurations per game or game type |
| **Button Mappings** | Document controller button layout configurations per game |
| **Performance Log** | Track FPS and power draw per profile configuration |
| **Game Library** | Organize games with their assigned Handheld Companion profiles |
